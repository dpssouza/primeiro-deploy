FERRAMENTAS DO LABORATÓRIO

Conhecimento conectado à realidade.

Durante as atividades, exploramos tecnologias presentes em ambientes profissionais de desenvolvimento e infraestrutura.

🐳

Docker Engine

Plataforma de containers instalada no servidor Linux. Executa o ambiente isolado que contém o servidor web.

  • Imagem: pacote usado como base para criar o container.
  • Container: instância em execução da imagem.
  • Portas: conectam uma porta do servidor à porta do serviço no container.
01
N

Nginx

Servidor HTTP que entrega os arquivos estáticos do site (HTML, CSS, JavaScript e imagens) ao navegador.

  • Recebe requisições HTTP.
  • Localiza e entrega o arquivo solicitado.
  • Utiliza a porta 80 dentro do container, conforme a configuração apresentada.
02
☁

AWS EC2 e Ubuntu

O EC2 fornece a máquina virtual na nuvem. O Ubuntu é o sistema operacional usado para administrar o servidor.

  • Acesso administrativo remoto por SSH.
  • Docker é executado no sistema Linux.
  • Regras de rede/firewall controlam as portas acessíveis externamente.
03
⚙

Docker Compose

Ferramenta usada para descrever e administrar os serviços do ambiente por meio de um arquivo YAML.

  • Define imagem e nome do serviço.
  • Configura portas e reinicialização.
  • Facilita iniciar, parar e consultar os containers.
04
⌘

Linux e SSH

O terminal permite administrar a instância remotamente e executar comandos de diagnóstico e implantação.

  • ls, cd e pwd: navegação.
  • docker compose ps: consulta serviços.
  • docker logs: consulta registros.
05
🌍

HTTP e navegador

O navegador faz a requisição ao endereço público e apresenta o conteúdo devolvido pelo Nginx.

  • HTTP é o protocolo usado no teste demonstrativo.
  • A porta publicada no host encaminha a requisição ao container.
  • O teste confirma a disponibilidade da página, não a saúde de todos os recursos da AWS.
06

Como o ambiente funciona

O site é publicado em uma máquina virtual na nuvem. O Docker executa o Nginx em um container, e o Nginx entrega os arquivos da página ao navegador.

01
AWS EC2 + Ubuntu

Máquina virtual que hospeda o ambiente. O acesso administrativo é realizado remotamente por SSH.

02
Docker Engine

Executa os containers de forma isolada, utilizando imagens como base.

03
Container Nginx

Servidor web que recebe requisições HTTP e entrega HTML, CSS, JavaScript e imagens.

04
Portas e rede

A porta publicada no servidor encaminha o tráfego para a porta 80 do Nginx dentro do container. As regras de segurança da AWS controlam o acesso externo.

05
Navegador

O visitante acessa o endereço público e visualiza a página disponibilizada pelo servidor web.

Importante: esta página apresenta a arquitetura configurada para a prática. Ela não possui integração de monitoramento em tempo real; portanto, não afirma que os containers estão ativos neste exato momento.
